# Contributing

Issues and focused pull requests are welcome. Discuss protocol or compatibility changes in an issue
first. Before opening a pull request, run `node tools/test.mjs`, import the package into a supported
Unity 6 project, and verify a non-development Web build.

Keep public APIs documented, preserve the sandbox boundary, and include `.meta` files for Unity
assets. By contributing, you agree that your contribution is licensed under the MIT License.
